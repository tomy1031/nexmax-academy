# マップの はいけい画像（先生むけ）

あたらしい ステージ（STEP 6 から）は、**ステージ 1つに つき 画像 1まい** です。
このフォルダに 画像を おくと、マップが のびて、その ステージの ピンが
じぶんの 絵の 上に 立ちます。コードは さわりません。

## 1. ファイル名の きまり

```
map_step<STEPの番号>_<なまえ>.webp
```

例: STEP 6 の ステージなら `map_step6_tokyo.webp`

- 番号は ステージの step と おなじ 数字に します。
- なまえは 半角の 小文字・数字・ハイフンだけ（`tokyo` `osaka` `server-room` など）。
- つかえる かたちは `.webp` `.png` `.jpg` `.jpeg` `.avif`。ふだんは `.webp`。

## 2. 絵を おくと どうなるか

- マップが 1画面ぶん 縦に のびます。
- その STEP の ピンが、じぶんの 絵の まんなかに 立ちます。
- 道の 点線と、道ぞいの ネクマックスも じどうで ついてきます。

絵が まだ 無くても、ステージは きえません。海の 色だけの 帯に ピンが 立ちます。
（`npm run lint:content` が「絵が まだ 無い」と おしえて くれます）

## 3. 絵は Codex で つくれます

`docs/skills/codex_image_generation.md` の **§9** に、おなじ 絵がらで
マップの 絵を つくる 手順と プロンプトが あります。
ClaudeCode に「STEP 7 の マップの絵を 作って」と たのんでも OK です。

## 4. 大きさ

**1024 × 1536**（たて長）。いまの 絵と おなじ 大きさに そろえて ください。
はばに 合わせて 表示するので、ひりつが ちがうと 上下が 切れます。

## 5. さいしょの 3まい（STEP 1〜5）

`map_seg1_cambodia.webp` `map_seg2_ocean.webp` `map_seg3_coast.webp` は
1つづきの 道として かかれた 3まい組で、STEP 1〜5 を うけもちます。
この 3まいは 名前を 変えたり けしたり しないで ください。
（STEP 5 までの ステージに `map_step5_...` のような 絵を おいても つかわれません）

## 6. つかわれない 画像

`map_seg` / `map_step` で はじまらない ファイルは、マップの はいけいには なりません。

- `map_cambodia.webp` `map_japan.webp` … つかいません
- `japan_goal.webp` … ゴールの おび（べつの ばしょ）
- `title_keyart.webp` `welcome_bg.webp` … べつの ページ

## 7. おいた あと

画面に 出るまで すこし じかん（1分ほど）が かかります。
出ないときは ページを もういちど ひらいて ください。

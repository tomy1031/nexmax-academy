# マップの はいけい画像（先生むけ）

マップは **ステージ 1つ ＝ 土地 1つ ＝ 画像 1まい**。
上から じゅんばんに つみあげて、そのあいだを 雲で つなぎます。

## 1. ふつうは スタジオから

ステージを ふやしたり へらしたり するのは、**スタジオ（`/studio`）** から できます。
ここに ファイルを おく ひつようは ありません。

1. スタジオで ステージを つくる（ステップの ばんごう＝マップの 上からの ばんごう）
2. 「マップの 土地」で 名前・よみ・ひとこと を 入れる
3. 絵を えらんで アップロードする
4. 「こうかい」を おす → 1分ほどで マップに 出ます

**へらす**ときは、そのステージを ひらいて「したがきを ほぞん」を おします。
マップから 消えますが、中身は のこります（また「こうかい」で もどせます）。

絵が まだ なくても ステージは 出ます（空色の おびに なります）。

## 2. 名前に 国の 名前を 入れない

土地の 名前は **景色の 名前**に します（「きりの やまなみ」など）。
国は これから 変わる かもしれないので、画面の ことばを 国に よせません。
まちの 名前・いせきの 名前（アンコールワット、プノンペン）は つかえます。

## 3. 絵の 大きさ

**たて長 1024 × 1536**。四辺は ぜんぶ 海。
上と下の 1わりは 海だけに して、島・建物・船を おかないで ください
（上下の 絵と つながらなく なります）。

## 4. 絵は Codex で つくれます

`docs/skills/codex_image_generation.md` の **§7.1** に、おなじ 絵がらで
つくる 手順と ことばが あります。
ClaudeCode に「STEP 7 の マップの絵を 作って」と たのんでも OK です。

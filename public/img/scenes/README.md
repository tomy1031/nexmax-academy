# マップの はいけい画像（先生むけ）

このフォルダに 画像を 1まい おくと、マップが のびます。コードは さわりません。

## 1. ファイル名の きまり

```
map_seg<番号>_<なまえ>.webp
```

例: `map_seg1_cambodia.webp` / `map_seg2_ocean.webp` / `map_seg3_coast.webp`

- 番号は 1 から つづく 数字。いまが 3 までなら、つぎは **4**（`map_seg4_◯◯.webp`）。
- なまえは 半角の 小文字・数字・ハイフンだけ（`ocean` `coast` `city-night` など）。
- 番号を とばすと 順番だけが 前に つめられます。とばさないで ください。

## 2. 1まい ふえると どうなるか

- マップが 1画面ぶん 縦に のびます。
- 停留所（ステージの ピン）を おける 数が **2つ** ふえます。
- 道の 点線と、道ぞいの ネクマックスも じどうで ついてきます。

ステージ そのものは スタジオで つくります。画像は「どこまで 道を のばせるか」を きめる ものです。

## 3. 画像の 大きさ

いまの 画像と おなじ たて・よこの ひりつに そろえて ください。
はばに 合わせて 表示するので、ひりつが ちがうと 上下が 切れます。

## 4. つかわれない 画像

`map_seg` で はじまらない ファイルは、マップの はいけいには なりません。

- `map_cambodia.webp` `map_japan.webp` … つかいません
- `japan_goal.webp` … ゴールの おび（べつの ばしょ）
- `title_keyart.webp` `welcome_bg.webp` … べつの ページ

つかえる かたちは `.webp` `.png` `.jpg` `.jpeg` `.avif` です。ふだんは `.webp` を つかいます。

## 5. おいた あと

画面に 出るまで すこし じかん（1分ほど）が かかります。出ないときは ページを もういちど ひらいて ください。

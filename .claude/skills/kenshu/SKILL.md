ルールをここに写さない（二重管理禁止。本体は Codex/Gemini からも読まれるツール共通の台帳）。

最小の流れ（詳細・役割表・モデル選定は本体）:

1. 機械が先: `node scripts/check_fast.mjs`（読みの照合を含む）。赤いうちは LLM 検収を回さない。
2. 触った領域から役を選び、並列に投げる（1体1観点）:
   - 教材・文言 → `rubric-checker`（担当セクション R1〜R8 をプロンプトで1つずつ）
   - 読み・content/ → `yomi-kensa`
   - 画面フロー → `playwright-player`（ペルソナを1つ指定）
   - エンジン・認証/DB・共有部品 → `code-critic`
3. 指摘の**和集合**を主スレッドが直し、赤かった検収だけ再実行。
4. 証拠（引用・スクショ・検査ログ）を PR に貼ってから `nexmax-release` へ。

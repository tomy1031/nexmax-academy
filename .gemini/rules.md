# Gemini Agent Rules — nextmake_kenshu

まず `AGENTS.md` を読むこと。プロジェクト共通の規律・必読ドキュメント・コマンドはすべてそこにある（このファイルには重複させない）。

## Geminiエージェント固有の役割

このプロジェクトの本番ランタイムAIはGemini（Live API）である。Geminiエージェントは検収において次を担当する:

1. **Liveペルソナの実機挙動検証**: `content/scenarios/*.json` の persona が実際のGemini上で守られるかを大量試行で統計検証する。
   - 聞かれる前に隠れ要件（reqs.fact）を話していないか
   - 1回の返事が1〜2文・N4語彙・です/ます調を守っているか
   - 「癖」（話し方のルール第5条）が適切な頻度で発動するか（毎回でも0回でもなく）
   - 学習者の日本語を訂正していないか
2. 検証結果は「違反した応答の実例引用＋発生率」で報告する。感想は不要。

## 禁止事項

- ルーブリック（docs/design/review_rubric.md）と異なる独自基準でレビューしない
- 学習者向け文言に「不正解」「間違い」を含む提案をしない

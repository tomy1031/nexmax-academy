2.2 朝礼メモの問題（ご指摘そのもの）

content/quizsets/asakai_memo.json は intro を持たず、いきなりこう始まります。

「きのう した ことは 何ですか。どこまで 終わりましたか。」

学習者には役も場面も渡されていません。だから「きのう何をしたか」を決められず、 ヒント（💡 たとえば、こんな こと）を開くまで書き出せません。 ヒントは足場であって前提ではない——ルーブリック R10 に入れた項目です。

直し方：メモを書かせるのをやめ、場面カードで「あなたはきのうこれをした」を渡す。 学習者が考えるのは「それをどう言うか」だけになります。

2.3 「はじめての 朝礼」を削除する理由

「そもそもいきなり朝礼ってなんの話ってなって、わけわからないし…何が初めてなのか？ 余計な『？』マークを生む要因」

まったくそのとおりで、加えて2つの規律にも触れています。

  • 順路（R9-1）：まんががページより先にあるので、「朝礼」が何かを知らないまま朝礼の話が始まります
  • ネガティブな例（規律10）：ヘンディさんの「ニャムさん、結論から言ってみましょう」は、 ニャムさんを「結論から言えていない人」として描いています。ニャムさんは実在の社員がモデルです

導入はページ（11）の冒頭と場面1の時間カードが担うので、まんがが無くても穴は空きません。

3朝礼と夕礼の違い（Web調査）

ご指定どおり調べました。結論はきれいに1行になります。

朝礼は「これからの ため」、夕礼は「きょうの ふりかえりの ため」。 朝は未来を向き、夕方は事実を落ち着いて振り返る——見ている向きが逆です。
朝礼（ちょうれい）夕礼（ゆうれい）／終礼
いつ始業のすぐあと終業の前
向きこれからやること（未来）きょうやったこと（過去）
おもな目的予定をそろえる／仕事モードに切りかえる／情報共有成果の確認／課題の洗い出し／残業時間の調整
ことば「きのう」「きょう」「きょう」「あした」
IT開発の現場ではデイリースクラム（朝会）と呼ばれ、15分で「昨日やったこと／今日やること／困っていること」を共有するのが標準。立ったまま行うことが多い

教材に載せる文案（N4前後・分かち書き）

【ページ「朝礼 — 朝の 報告」に 足す 節】

見出し: 朝礼と 夕礼は、どこが ちがうの？

  朝礼は、これから する ことの ための 会です。
  夕礼は、きょう した ことを ふりかえる ための 会です。
  見て いる 向きが ぎゃくです。

  ・朝礼 … 「きのう」と「きょう」を 話します。
  ・夕礼 … 「きょう」と「あした」を 話します。

  話す 中身の 3つ（した こと・する こと・こまって いる こと）は 同じです。
  ことばだけが 変わります。

  ITの 開発チームでは、朝の 会を「デイリースクラム」とも 言います。
  立ったまま、15分で 終わらせる チームが 多いです。

絵で見せる所：この節の図は、#357 の blocks[15]「朝の 会・夕方の 会・文字で 書く 会」がそのまま使えます （矢印の向きを、朝＝右向き（これから）／夕＝左向き（ふりかえり）にすると、字を読まなくても違いが分かります）。

出典: 朝礼と終礼の目的や効果は？（HRドクター）、 朝礼の目的はなに？、 朝礼と終礼の目的や効果は？（kokolog）、 デイリースクラムとは？、 デイリースクラムが15分で終わらないのですが（アトラクタ）

4ミーティングの作り直し

4.1 いま と これから

いまこれから
進み方アプリが5問を順に聞く。学習者は1問に1文で答える学習者が1本の報告をする。アプリは足りない所だけ聞き返す

4.2 場面カード（メモの置きかえ）

報告する前に、学習者に「あなたのきのう・きょう」を渡します。考えるのは日本語だけにするためです。

┌─ 月曜日 9:30 ─ 開発チームの 朝礼 ────────────────┐
│                                                     │
│  🧑‍💻 あなた（PG）の きのう                            │
│     ・ログイン画面の テストを した                    │
│     ・20この うち 16こ 終わった                       │
│                                                     │
│  📅 きょう する こと                                  │
│     ・のこりの 4こを テストする                        │
│                                                     │
│  ⚠ こまって いる こと                                 │
│     ・エラーの 意味が 分からない（30分 止まって いる）  │
│                                                     │
└─────────────────────────────────────────────────────┘

絵で分かるように：このカードは字を並べません。 チェックの付いた四角16こ／空の四角4こ、時計の絵、赤いエラーの札——数と状態を絵で出し、字は添えものにします （constraints「絵で分かるようにする」）。

4.3 パネルと 追い質問

場面ごとに「言えてほしい要素」をパネルにします。1回の発話で当てはまるものは全部開きます。

✅ きのう した こと ✅ どこまで（数字） ？ きょう する こと ？ こまって いる こと ？ 見込み

例：学習者が「きのうは テストを しました。16こ 終わりました。」と言うと、 「きのう した こと」と「どこまで」の2枚が同時に開きます。 残りについて、ヘンディさんが未開封の中から1つ選んで聞き返します。

未開封のパネルヘンディさんの聞き返し（例）
きょう する こと「ありがとう ございます。きょうは 何を しますか。」
こまって いる こと「いま こまって いる ことは ありますか。小さい ことでも かまいません。」
見込み「それは、どのくらい 時間が かかりそうですか。」
お願い「わたしに して ほしい ことは ありますか。」
影響「その こまりごとは、あしたの リリースに 影響が ありますか。」
止まらないための決めごと：同じパネルの聞き返しは2回まで。 2回聞いても開かなければ、ヘンディさんが言い方の例を見せて、その場面は先へ進みます （0点でも肯定で終わる／未達成は「次に試す行動＋例文」に変える＝設計01 P8）。

4.4 おわり方（ほかのメンバー → 藤木さんの総括）

パネルが全部開いたら、学習者は聞く側にまわります。ここは読むだけ（産出のあとの休み）。

  1. ニャムさん（同期）が報告する — 学習者と同じ形。できている例として置く
  2. 奥田さん（先輩）が報告する — 数字と見込みが入った、少し上手な例
  3. 藤木取締役がまとめる — お客さまのようすとチームがどこへ向かうか
藤木（例）：「みなさん、ありがとう ございます。お客さまは、来週の デモを 楽しみに して います。 きのう『画面が 分かりやすい』と 言って くださいました。
いま いちばん あぶないのは ログインの エラーです。◯◯さんが 見つけて くれたので、きょう 手を 集めます。 こまって いる ことを 朝に 出す。それが この チームの 強さです。」

ここが「なぜ朝礼をするのか」の答えになります。 自分の報告がお客さまのところまで届いていることが、藤木さんの口から見える形になります （報告ステージでリスニングに入れた因果と、同じ筋です）。

4.5 💗 を外す

「正しく自分の状況を伝えられるのが重要なことなので、距離もエピソードも無駄しかありません」

この教材では affection を持ちません。 affection はスキーマ上すでに任意なので、データから外すだけで済みます（エンジン変更は不要）。

ただし1つだけ確認させてください：ヘンディ先輩の 「日本へ 来て 1か月目、わたしは バグを 三日 隠しました」の話は、報告ステージのミーティング（💗の向こう）にも入っています。 N3ペルソナが「このステージで一番おもしろい」と言った話です。 💗を外すなら、この話は「藤木さんの総括」と同じ場所（最後に必ず読める所）へ移すのが良いと考えています（10章 判断3）。

# 自動でたしかめること — 1枚（先生・クライアント用）

**ねらい: 出す前の「手で6教材をさわって確かめる」を、機械にやらせること。**

コードを直すたび（PRごと）に、GitHub が自動で
**アプリを起動 → かいしゃステージの6教材を学習者と同じ順に最後まで遊ぶ**ところまで
やります。1つでもおかしければ PR は赤くなり、そのままでは main に入りません。

鍵（ログイン）は要りません。Supabase の設定が無いとアプリは**デモモード**（ログイン不要）で
動くので、機械はそのまま中に入れます。

---

## 1. どこで走るか

| いつ | どこ | かかる時間のめやす |
| ---- | ---- | ------------------ |
| PR を作る／直すたび | GitHub Actions の `CI` → `e2e` | 約 5〜7分（うち通し検証そのものは約1分） |
| PR を作る／直すたび | GitHub Actions の `CI` → `size`（大きさの見張り） | 約 5〜8分 |
| これまでどおり | `CI` → `check`（型・整形・単体テスト790件・ビルド） | 約 3〜5分 |

3つは同時に走ります。**`check` はこれまでと同じ**で、何も変わっていません。

---

## 2. 自動でたしかめること（かいしゃステージ・6教材）

**端末に何も置かずに始めます。** つまり関門（前の教材を終えるまで開かない）も本物のまま通ります。

| # | 教材 | 機械が見ていること |
| - | ---- | ------------------ |
| — | ステージのトップ `/kaisha` | 6教材が順にならぶ／進み具合が 0 → 3つ → 6つ と動く／100%になる |
| 1 | 読み物「かいしゃの しらべかた」 | 🔊 読み上げボタンが出ている／ことばチップをタップすると**読み・英語・意味**が出る／最後まで読むと「つぎは」が出る |
| 2 | もんだい「しらべかたの かくにん」 | 6問（4択5問＋複数えらぶ1問）を答えて 6/6 になる |
| 3 | 読み物「ネクストメイクを しらべよう」 | 外部リンクのカードが**別のタブで開く形**（`target="_blank"`）で出ている／行き先が実サイト |
| 4 | もんだい「ほうこくの じゅんび」 | 語群の穴埋め5問／**自由入力4問がひらがな・「です」つき・文で答えても通る**／「あなたの こたえ」に自分の書き方がそのまま出る |
| 5 | ミーティング「ヘンディさんに 報告する」 | 入室前に「はなす まえに」とふりがな／**カメラは既定でOFF**（映像は出ない）／ノックして入ると**「こう 言えます」が最初から見えている**／文字で答えると札が1枚ずつ開く（10枚）／「まだ 言えない（つぎへ）」で答えずに進める |
| 6 | ミーティング「松井社長と 話す」 | 答えるたびにハートが増える／完走すると**とっておきの話**が開く／「ステージ クリア」が出る |

### あわせて見ていること

- **順路（関門）**: 何もしていない端末で6番目を直接ひらくと「まだ この きょうざいの じゅんばんでは
  ありません」が出る。行き止まりにしない道（先にやる教材へのボタン・「それでも 見る」）も動く。
- **つづきから**: もんだいを2問答えて離れ、もどると「🔖 まえの つづきから はじめます（2もん こたえました）」が
  出る。「はじめから やる」も効く。
- **ふりがなの覆い**: 7つの主要画面で、**ルビの付いていない漢字**が画面に出ていないか（下の §4 参照）。
- **AIが居なくても止まらない**: Gemini の鍵が無いとき、ほめる一言と「AIの せっていが まだです」が出て、
  そのまま次へ進める（＝鍵の無い教室でも会話が終われる）。
- **AIが居るときの1往復**: 鍵があるときだけ、文字で答えて **3段（すばらしい／つたわりました／もう いちど）の
  どれかとほめ言葉**が返ることを1回だけ確かめます。鍵が無ければここだけ飛ばします。

## 3. まだ人の目が要ること（自動では見ていません）

正直に書きます。ここは**先生とクライアントの目**が残ります。

| 残っているもの | なぜ機械では見られないか |
| -------------- | ------------------------ |
| **マイクで声が届くか**（🎤 声で 話す・Live対話） | 本物のマイクとブラウザの許可が要ります。機械は「文字で答える道」だけを通しています |
| **相手の声・口の動きが自然か** | 音の良し悪しは聞かないと分かりません |
| **絵の good / bad**（ネクマックス・まんが・背景） | 出ている／出ていないは見ますが、**似ているか・かわいいか**は人が決めます |
| **文章のやさしさ・言い回し** | 禁止語（「不正解」など）は `lint:content` が見ますが、**読めるかどうか**は人が読んで決めます |
| **実サイト（nextmake.site）の中身** | リンクが開く形かは見ますが、**外のサイトは開きに行きません**（サイトが更新されると答えが変わるので、学期の前に先生が突き合わせてください — `docs/teaching/kaisha_授業の1枚.md`） |
| **スマホ実機の見え方**（390px の崩れ） | いまは 1280px の画面幅だけで走らせています |
| **ログインしたときの動き** | 検証はデモモード（ログイン不要）で行います。ログインまわりは STG で確かめてください |
| **かいしゃ以外のステージ** | いまは「かいしゃを しる」だけを通しています |

## 4. いま「ふりがなが付いていない」と分かっているところ

自動の検査が見つけた**4か所**です。増えたら PR が赤くなります（減らしたら一覧から消します）。

| 出ている文字 | どこ |
| ------------ | ---- |
| ことば — タップ すると いみが **出**るよ | 読み物のことばチップの見出し |
| **人**が さんかちゅう | ミーティングの画面の上 |
| 🎤 **声**で **話**す | ミーティングのボタン |
| それでも **見**る | 順番が来ていない教材を開いたときの逃げ道 |

どれも教材の本文ではなく**画面の飾りの文字**です。直すかどうかは画面の持ち主が決めます。

## 5. 上げる大きさの見張り（無料枠 3MiB）

2026-08-16、Worker の大きさが上限まで**あと 5KiB** のところに来ていて誰も気づけず、
デプロイが止まりました。これからは PR ごとに測って、ログに出します。

| いまの大きさ | どうなるか |
| ------------ | ---------- |
| 〜2867 KiB（2.8MiB） | ✅ そのまま通す |
| 2867〜3072 KiB | ⚠️ 警告を出す（**まだ止めない**。減らす手を打つ合図） |
| 3072 KiB（3MiB）超え | 🛑 PR を落とす |

PR の Checks の `size` を開くと、いちばん上のまとめに表になって出ます
（2026-08-16 時点は **1822 KiB・59%・のこり 1250 KiB**）。

---

## 6. 落ちたときに見るところ

1. PR の **Checks → CI → e2e** を開く。どの手順で止まったかが日本語で出ます。
2. 画面を見たいときは、同じページの下の **Artifacts → `e2e-画面とレポート`** をダウンロード。
   - `e2e-screens/` … 節目ごとの画面写真（01 ステージのトップ 〜 12 おわったステージ）
   - `playwright-report/` … `index.html` を開くと、どこで止まったかを操作の順に追えます
3. 見なくても合否は分かります。**開くのは「なぜそうなったか」を知りたいときだけ**で大丈夫です。

## 7. さわる人向けのメモ

```
npm run build                                  # 先にビルドしておく
npx playwright test                            # 通し検証（サーバは自動で立つ）
npx playwright test --ui                       # 画面を見ながら1歩ずつ
node scripts/check_worker_size.mjs             # 大きさだけ測る（先に npm run cf:build:local）
```

- `@playwright/test` は **package.json に入れていません**。CI のジョブが
  `npm install --no-save @playwright/test@1.56.1` で入れます（版はブラウザと組で固定）。
  手元で動かすときも同じ版を入れてください。
- 開発コンテナのように**ブラウザが最初から入っている**環境では、
  `E2E_CHROMIUM_PATH=/opt/pw-browsers/chromium-1194/chrome-linux/chrome npx playwright test` のように
  置き場を渡せば、そのブラウザを使います。
- Gemini の鍵は **端末（localStorage）に置く道**でしか渡していません（学習者と同じ BYOK の経路）。
  **ビルドには渡しません** — OpenNext が `.env*` をバンドルへ焼き込むためです（`docs/deploy.md` §0.2）。
  鍵をさわるテストのファイルだけ、記録（トレース）を切ってあります（成果物に鍵を残さないため）。

# アプリの 要件定義（youken2）— 要る絵の一覧（2026-09-08）

「要件定義（抹茶）」の 続編ステージを 作ったときに、**まだ 無い 絵**を 1か所に まとめたもの。
画面には いま「🖼️ ここに 絵が 入ります」の 点線わく（記事）か、頭文字の 丸（Zoom の タイル）が
出ている。空けたままだと 作り忘れが 誰にも 見えないため。

## 作りかた

`docs/skills/codex_image_generation.md`（image-gen-2・一貫性ルール）に従う。
**手描きSVGで 自作しない**（AGENTS.md 絶対規律7）。人物は §6.5（人間キャラ）の 手順で、
**先に 設定画を 1枚 作ってから** 各カットを 撮る。既存の `public/img/youken/yamamoto.webp`
（山本社長）と 絵柄を そろえる（参照入力に 渡す）。

差しかえは 2か所:

1. `public/img/youken2/<ファイル名>.webp` に 置く（`cwebp -q 82`）
2. 教材データの 該当スロットを `{"src": "/img/youken2/<ファイル名>.webp", "refs": [], "status": "done"}` にする

英語の 生成プロンプト案は、教材データの 各スロットの `prompt` に そのまま 入れてある。

# 報連相 — 要る絵の一覧（2026-08-30）

報連相3ステージに「もっと 楽しく」の教材を足したときに、**まだ 無い 絵**を
1か所に まとめたもの。Cloud のセッションでは 画像を 生成できないため、
データには **英語の 生成プロンプトだけを 保存**して あり、画面には いま
「🖼️ ここに 絵が 入ります」の 点線わくが 出ている（`ImageSlotFrame` / `ImageBlock`）。
空けたままだと 作り忘れが 誰にも 見えないため。

**この一覧は ローカルの 生成セッションへの 引き継ぎ書**である。上から 順に 作れば よい。

## なぜ 急ぐか（優先度の 根拠）

2026-08-30 の 指定:「生徒は N4レベルに 満たない 子が 多い。文章で 理解する ことが
むずかしい 人も いる。**絵を 使う ことは 有効で、絵で 理解できる 内容に する**」。

とくに **場面クイズ（優先度 高）は 絵が 本体**の 教材である。「いま 話しかけて いい？」を
字で 書き並べると、測って いるのが 場面の 読みでは なく **長い 日本語を 読む 速さ**に なる
（`quizCommon.image` を 足した ときの 判断。`src/content/schema.ts`）。

## 作りかた

`docs/skills/codex_image_generation.md`（image-gen-2・一貫性ルール）に従う。
**手描きSVGで 自作しない**（AGENTS.md 絶対規律7）。

差しかえは 2か所を 直すだけ:

1. 画像を `public/img/...` の 置き場に 置く（下の 表の パス）
2. 教材データの 該当スロットを
   `{"src": "/img/...", "prompt": "（そのまま 残す）", "refs": [...], "status": "done"}` にする

`status` が `done` に なった 瞬間、点線わくが 絵に 変わる。
**プロンプトは 消さない**（あとで 少し 直して 作り直す ときに 要る）。

> ⚠ データは `scripts/gen_hourensou_content.mjs` が **作り直す**。手で JSON を 直したら、
> 同じ 直しを この スクリプト側にも 入れる（次に 走らせた ときに 消えるため）。
> 画像だけを 差しかえる 運用に するなら、スクリプトの 該当スロットに `src` と
> `status: "done"` を 書き足すのが 確実。

## 3. これは **要らない**（絵を 作らなくてよい）

- **報告クエスト・れんらくビルダー・済スタンプ**（`public/tools/hourensou/*.html`）は、
  絵文字を 大きく 出して 場面を 作る 作り。画像ファイルは 使わない
- 報連相の **講義・スキット・リスニング**の 絵は、旧アプリからの 当て画像を
  そのまま 使って いる（`public/img/hourensou/`）。**作り直しは いつでも よい**——
  差しかえたい ときは 同じ 名前で 上書きすれば 画面は そのまま 変わる

## 4. 作った あとの 確かめ

```
npm run lint:content     # スキーマ・ふりがな・焼き込みずれ
npm run gen:content      # 焼き込みモジュールを 作り直す（これを 忘れると 画面は 変わらない）
```

絵が 入ったか どうかは、`/soudan`（場面クイズ）と `/renraku`（まんが）を 開いて
点線わくが 消えて いれば よい。

# 会社を知る — 要る絵の一覧（2026-08-27）

配布資料（`会社研究/` の HTML 4枚）から 教材を 作り直したときに、**まだ 無い 絵**を
1か所に まとめたもの。画像は あとから 差しかえる前提で、**画面には いま
「🖼️ ここに 絵が 入ります」の 点線わく**が 出ている（`ImageSlotFrame` /
`ImageBlock`）。空けたままだと 作り忘れが 誰にも 見えないため。

## 作りかた

`docs/skills/codex_image_generation.md`（image-gen-2・一貫性ルール）に従う。
**手描きSVGで 自作しない**（AGENTS.md 絶対規律7）。

差しかえは 2か所を 直すだけ:

1. `public/img/articles/kaisha_matsui_junbi/<ファイル名>.webp` に 置く
2. 教材データ（`content/articles/kaisha_matsui_junbi.json`）の 該当スロットを
   `{"src": "/img/articles/kaisha_matsui_junbi/<ファイル名>.webp", "refs": [], "status": "done"}` にする

`status` が `done` に なった 瞬間、点線わくが 絵に 変わる。

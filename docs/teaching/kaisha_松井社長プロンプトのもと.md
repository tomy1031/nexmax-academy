# 松井社長プロンプトのもと（2026-08-27）

対話ゲーム「松井社長と LiveAIで 話そう」（`content/meetings/kaisha_matsui.json`）の
`persona` / `judgePrompt` / `talkGame.openers` / `talkGame.listenHints` に
**何を根拠に何を書いたか**を残す。プロンプトだけを読んでも、どこまでが事実で
どこからが役づくりかが分からないため。

## なぜ足したか

学習者は STEP 5 の対話の後半で、**社長に「聞く ばん」**が回ってくる。
ところが社長役に渡していた材料は**会社の事実だけ**で、
「どうして 会社を 作りましたか」「どうして カンボジアに 来ましたか」に
答える材料が 1行も無かった。作り話をさせないと決めてある以上、
材料が無ければ社長は「まだ 決めて いません」としか言えない——
**教材がいちばん練習させたい質問に、いちばん薄い返事が返る**状態だった。

## 3つのどこに何を入れたか

### 1. `persona`（社長の返事の材料）

会社の事実に加えて **【私自身の こと（聞かれたら 答える）】** を新設した。
学生が聞きそうな 7つに、先に答えを用意してある——
会社を作った理由／カンボジアに来た理由／どんな学生と働きたいか／
日本で働くために今すること／これからどんな会社にしたいか／
学生にいちばん大切な力／すきな仕事の時間。

いちばん効くのは**プノンペンで学生と同じ授業を受けた話**である。
`talkGame.reward`（好感度 100% のごほうび）と同じ出来事を指しているので、
学生が先に質問で引き出しても、あとでごほうびを聞いても、**話が食い違わない**。

作り話の禁止は残したうえで「上に 無い ことを 聞かれたら、知らないと 言って
かまいません」を足した。材料を厚くすると、AIは**足りない所を埋めたくなる**。

### 2. `judgePrompt`（採点の基準）

事実の一覧に上の出どころ分を足した。効きめが大きいのは**もう 1つの直し**である。

> **社長 本人に しか 聞けない しつもんも concrete を true に します。**

前は「サイトの具体的な中身（サービス名・出来事・数・人の名前）に触れた しつもん」
だけを concrete にしていた。すると「どうして カンボジアに 来ましたか」は
サービス名を含まないので **false** になる——**教材がいちばん練習させたい質問が、
そのまま減点される**という向きになっていた。

これは 2026-08-27 に 1度直したのと同じ型の事故である（教材側の見かたは広く、
エンジン側の一覧は狭く、そのすきまに「カンボジアの プログラム」が落ちて
CI の `taiwa-live` が落ちた）。**ものさしが 2つあると、必ずどちらかが正しくない。**

### 3. `talkGame.openers` / `listenHints`（質問）

- opener に 2つ追加 … プノンペンの大学で同じ授業を受けた話／カンボジアに会社を作った話。
  どちらも**学生の側に返事の材料がある**問い（自分の大学・自分の国）にしてある。
- listenHints に 3つ追加 … 「どうして カンボジアに 来ましたか。」
  「どんな 学生と はたらきたいですか。」「まちがえるのが こわいです。どう すれば いいですか。」
  3つめは事実の質問ではない。**質問の形なら concrete になる**ことを、
  いちばん怖がっている学習者にも使える形で示すために置いた。

## 確かめかた

```
npm run lint:content     # openers / listenHints の ふりがな覆い（persona と judgePrompt は対象外＝AIへの指示）
```

実機は `tests/e2e/taiwa-live.spec.ts`（`GEMINI_API_KEY` があるときだけ走る）。
`persona` / `judgePrompt` は画面に出ないので、**返事の中身を見るには実際に Live へ通すしかない**。

## 2026-08-31 の直し（準備フォームが 5問 → 3問）

「④カンボジアの いい ところは？」「⑤松井社長に 何を 聞きたい？」をフォームから外した
（ユーザー指定・[#266](https://github.com/tomy1031/nexmax-academy/issues/266)）。
`persona` と `judgePrompt` の「学生が書いてきた5つ／①〜⑤」も3つに直してある。

**しつもんの ばんの 見かたは変えていない。** ⑤が無くなったぶん、学習者はその場で質問を
考えることになる。準備なしで出てきた質問を減点する向きにしないため、
「社長 本人にしか聞けない しつもんも concrete を true にする」はそのまま残す
（むしろ効きめが増える）。

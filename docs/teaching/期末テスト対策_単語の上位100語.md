# 期末テスト対策：単語の上位100語（入れ替え用）

2026-11-20 作成。tomy さんの依頼「今までの内容の中から、IT業務でよく使う汎用性の高い単語を40個抽出」「上位100の単語をリスト化（適切でない単語があった場合はその中から私が選んで入れ替える用）」。

- **1〜40位（✅）が、いまの単語テスト「期末テスト 対策の ことば」に入っている40語**です。
- 入れ替えたいときは「◯位の◯◯を外して、◯位の◯◯を入れて」と言ってください。
- 候補は、会社を知る・報連相（報告・連絡・相談）の単語テストに入っている314語です。
- 並べ方：IT の仕事でよく使うか（どの会社・どの現場でも使うか）を先に見て、同じくらいなら教材に出てきた回数が多い順にしました。
  会社の名前・サービスの名前のような、その会社だけの言葉は入れていません。
- 41〜100位には、会社概要の言葉（株式会社・取締役・実績など）と、カタカナの IT 用語（バグ・サーバー・リリースなど）を入れています。
  カタカナの言葉は読みがやさしいので、40語には漢字の言葉を優先しました。
- 「出てきた教材」は、その言葉が本文に出てくる教材です（会社＝会社を知る、報告＝報告・朝礼と夕礼・報告のリスニング）。「回数」は本文に出てきた回数です。

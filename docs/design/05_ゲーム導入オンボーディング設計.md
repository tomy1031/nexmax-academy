# ゲーム導入オンボーディング設計 — タイトル・性格診断・マップTOP

**作成日**: 2026-07-25
**位置づけ**: ユーザー提供のUIモックアップ5枚（タイトル／チュートリアル設定／性格診断／結果／マップ）を正とする画面仕様。
ビジュアルトークンは `04_ビジュアルテーマ.md`・`globals.css` を基盤に、モックアップの豪華なゲームUI表現を上乗せする。
文言は `01_理解設計ガイド.md` の規律（禁止語・N4・ふりがな）に従う。

## 0. 理解設計（作る前の3行）

1. **前提**: 生徒はスマホゲームの「タイトル→設定→マップ」の流れを知っている。Googleログインも見たことがある。
2. **新情報**: 「性格診断で自分に合うパートナー（ネクマックス）が決まる」こと。一度に入れる新概念はこれ1つ。
3. **つまずき予測**:
   - 質問の日本語が読めない → 「やさしい日本語／日本語／English」の3言語トグルを診断画面に置く。
   - Gemini APIキーが何か分からない → 必須にしない。「あとから せっていできます」を明記し、スキップ可能にする。
   - ログインを強制されると感じる → ログインも任意。たいけんモードのまま進める。

## 1. 全体フロー

```
/            タイトル画面「ゲームを始める」
  └→ /welcome ステップ1: チュートリアル＋せってい（Googleログイン任意・Geminiキー任意・性別必須）
       └→ ステップ2: ネクマックス性格診断（12問・3言語）
            └→ ステップ3: 結果（あなたに合うネクマックス）→「はじめる」
                 └→ /map   マップTOP（上カンボジア→下日本の縦スクロール／カード表示切替）
```

- プロフィール保存済みならタイトルのメインボタンは「つづきから」（→ /map）。「もういちど せっていする」の小リンクで /welcome へ。
- 旧 `/`（home-shell）は廃止し、/map が新TOP。`/tutorial`（6ステップ紹介）は残すがメイン導線から外す。
- ログインの redirect は `/auth/callback?next=/welcome`（ログイン後ウィザードに戻る）。

## 3. 性格診断（12問・はい/いいえ・3言語）

- 言語トグル: 「やさしい日本語」（分かち書きひらがな・既定）／「日本語」（通常表記＋ふりがな）／「English」。

## 4. 画面仕様

### 4.2.1 ステップ1: チュートリアル＋せってい

- 見出し: 「⭐ はじめての チュートリアル ⭐」／パネル内見出し「ネクマックスアカデミーで、楽しく 学ぼう！」（楽にふりがな）。
- 紹介カード3枚（横並び・イラストは絵文字＋既存キャラ画像でよい）:
  1. 「日本の IT の おしごとを 学べる！」— プログラミングや IT の しごとを たのしく まなべるよ！
  2. 「チームで コミュニケーション！」— なかまと はなして、アイデアを 出しあって せいちょうしよう！
  3. 「日本の IT パスウェイを すすもう！」— いろいろな ステージを クリアして、ゴールを めざそう！
- せってい3枚（横並びカード）:
  - **Googleでログイン**（任意）: 「アカウントで ログインして、データを あんぜんに のこそう！」＋Google Gボタン。authReady=false時は「じゅんびちゅう」表示。ログイン済みなら「✅ ログインずみ」。
  - **Google Gemini APIキー**（任意）: 「Gemini と つなぐと、AI が まなびを サポートします！」＋パスワード型input＋目アイコンで表示切替。下に「？ Gemini APIキーは、あとから せっていすることも できます。」保存先はlocalStorageのみ（サーバ送信・DB保存はしない）。
  - **性別（せいべつ・必須）**: 「あなたの せいべつを えらんでね。」男性／女性／その他 の3ボタン（絵柄つき・選択で枠色）。
- 下部中央: 「⭐ つぎへ ⭐」（金・特大）。性別未選択なら無効＋「せいべつを えらんでね」。
- 補足: 「🛡️ あんぜんに ほごされます」を小さく表示。

### 4.3 マップTOP `/map`

モックアップ: 最上部アンコールワット島（START）→ 海と島々（アジアの寺院島・ジャンク船・近代都市島）→ 最下部に日本（鳥居・富士山・東京タワー・さくら並木、GOAL）。白い点線の道が蛇行し、色付きノードとステップチップが並ぶ。

- **背景**: 縦長ページ（目安 250〜300vh）。`scenes/map_cambodia.png`（上半分）と `scenes/map_japan.png`（下半分）を縦に重ね、境目はCSSグラデマスクでブレンド（両画像とも境目側は外洋のみの構図にして継ぎ目を隠す）。
- **START/GOALバナー**: HTMLの木札風（茶系グラデ＋白文字）。START!「アンコールワット／カンボジア」上部中央、GOAL!「日本」最下部（日本にふりがな）。
- **道**: SVGの白丸点線パスが上→下に蛇行。ステージノード（楕円・タイプ色・白フチ・下影）を道上に配置。現在地ノードはピンク＋パルス。クリア済み=色付き、未開放=白。
- **ステージチップ**: 各ノードの左右交互に配置。内容「STEP 0n＋よみがな＋タイトル＋種別アイコン（▶動画風/👥ペア/🌐単語）＋チェブロン」。タップで展開: 説明1行＋「すすむ」ボタン（未実装先は『じゅんびちゅう です。もうすこし まってね！』のトースト）。
- **ステージ定義**（`src/content/stages.ts`・データ駆動で追加可能に）:
  1. STEP 01 IT単語帳（たんごちょう）— 単語 — leaf
  2. STEP 02 企業の仕組み（きぎょうの しくみ）— 動画/読解 — sky
  3. STEP 03 報告（ほうこく）— ペアワーク — coral/pink
  4. STEP 04 連絡（れんらく）— 動画 — sky-soft
  5. STEP 05 相談（そうだん）— ペアワーク — leaf
- **道沿いキャラ**: types 4色を道の脇に点在（bob・display画像は標準版）。
- **HUD（右上・固定）**: 「⭐ Lv.n」「🪙 コイン」「💎 ジェム」ピル＋アバターカード（パートナー画像＋「◯◯の ネクマックス」＋緑の●）。初期値 Lv.1／0／0（プロフィールから読む。まだ稼げないので0でよい）。
- **左サイドバー（固定・デスクトップ）**: 縦長丸パネルに ☰／マイページ／単語（たんご）／チーム・ペア／ショップ／«（折りたたみ）。未実装先はトースト「じゅんびちゅう です」。モバイルは☰ドロワー。
- **現在のレッスンカード（左上・固定〜絶対配置）**: 赤ピル「✦ 現在のレッスン ✦」（現在にふりがな）＋STEP番号＋タイトル＋種別＋説明＋進捗バー（n / 5 ステージ）。
- **アクションボタン（カード下）**: 「▶ 続きから — ステージを つづける」（ピンク大）／「📖 単語を勉強 — たんごを ふやして レベルアップ！」（金大）。※「シナリオ」という語は現段階で未定義のため「ステージ」を使う。
- **カード表示切替**: HUD付近にトグルボタン「🗺️ マップ ⇄ 🃏 カード」。カード表示=ステージをcard-popのグリッドで一覧（STEP番号・タイトル・よみ・種別・状態・すすむ）。選択はlocalStorageに保存。
- ヘッダー簡略: 左上ロゴ小（クリックで `/`）。ログイン状態表示・ログアウトはマイページ（将来）へ寄せ、当面サイドバー☰内に置く。

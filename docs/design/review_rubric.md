# 検収ルーブリック（証拠必須）

**使い方**: レビューエージェントは1回の実行で**1セクションだけ**を担当する（注意の希釈を防ぐ）。各項目は「質問」に対して**該当箇所の引用（ファイル名＋行 or フィールドパス）を証拠として**回答する。引用できない「合格」は無効。違反を見つけたら勝ち、というスタンスで読む。感想・褒め言葉は不要。

出典: `01_理解設計ガイド.md` の13原則と品質チェックリスト。機械検査（`npm run lint:content`）で落ちる項目はここに含めない。

---

## R1. 役割と物語（P1, P7）

| # | 質問 | 合格条件 |
|---|---|---|
| R1-1 | 学習者の役割と状況を与えている箇所を引用せよ | 最初の画面/ミッション部にある |
| R1-2 | 相手役の人間的動機（利他・理念・家族等）が見える箇所を引用せよ | 冒頭セリフか調査素材内にある |
| R1-3 | 相手役の「癖」を定義している箇所を引用し、それが練習させたい技法と対応するか述べよ | 癖は1つだけ・技法から逆算されている |
| R1-4 | 学習者の母国・語学力が強みとして扱われる箇所はあるか。あれば引用せよ | 任意（シリーズ内に1箇所あればよい） |

## R2. リアリティ（P3）

| # | 質問 | 合格条件 |
|---|---|---|
| R2-1 | 案件の数字（価格・人数・頻度・予算）を3つ以上引用し、業種・規模との整合を判定せよ | ダミー数字（きりの良い無根拠値）でない |
| R2-2 | 納期の理由となる事業イベントを引用せよ | 「◯ヶ月後」だけの納期は違反 |
| R2-3 | 結論（技術選定・優先順位等）を必然にする制約を列挙せよ | 制約が2つ以上で結論を指す |

## R3. 情報設計（P2, P4）

| # | 質問 | 合格条件 |
|---|---|---|
| R3-1 | 調査素材に埋まっている伏線と、それが回収される会話箇所を対で引用せよ | 1対以上 |
| R3-2 | 各調査クイズの答えの根拠を模擬ページから引用せよ | 全問がページ内から引ける |
| R3-3 | 情報開示が学習行為を鍵にした段階開放になっている箇所を引用せよ | 最初から全部読める構成は違反 |

## R4. 階段と産出（P6）

| # | 質問 | 合格条件 |
|---|---|---|
| R4-1 | インプット→変換→産出の各段に対応する画面/セクションを列挙せよ | 3段すべて存在し、産出で終わる |
| R4-2 | 産出課題の**直前**にある足場（例文・型文・2段階ヒント）を引用せよ | 引用できなければ違反 |
| R4-3 | ヒントの2段目を引用し、完成解を与えていないことを確認せよ | 穴あきパターン文まで。答えを言ったら違反 |
| R4-4 | 最終成果物と模範解答（ゲート付き）の場所を示せ | 両方あり、模範解答は隠されている |

## R5. フィードバックと感情（P7, P8）

| # | 質問 | 合格条件 |
|---|---|---|
| R5-1 | 誤答時のフィードバック文言をすべて引用せよ | 全てが励まし＋リソース誘導。正解の即開示は違反 |
| R5-2 | 0点・全滅時に表示される文言を引用せよ | 肯定で終わる救済文言がある |
| R5-3 | 未達成項目の表示を引用せよ | 「次に試す行動＋例文」に変換されている |
| R5-4 | 相手役AIの感情が学習者の良い行動に反応するルールを引用せよ | AI対話がある教材では必須 |

## R6. 日本語の足場とレベル差（P10, P11）

| # | 質問 | 合格条件 |
|---|---|---|
| R6-1 | 実務語彙を平易語に置換してしまっている箇所はないか。あれば引用せよ | 「要件定義」→「決めること」等は違反 |
| R6-2 | 学習者が自分で操作できる負荷調整（ふりがな・速度・Drag/Type・ヒント）を列挙せよ | 2種以上 |
| R6-3 | 語彙の先出し（6語前後）と、その語が本編で再登場する箇所を対で引用せよ | 先出し語が本編で使われている |
| R6-4 | 星・達成の条件を引用せよ | 合格ラインは低く、上限は高い（2軸）になっている |
| R6-5 | 学習者向け画面に概念ラベル（「オープンクエスチョン」等）やUIメタ用語（「表裏」等）が出ていないか。あれば引用せよ | 出ていたら違反 |

## R7. AI対話の統制（P12）※AI対話がある教材のみ

| # | 質問 | 合格条件 |
|---|---|---|
| R7-1 | answer/feeling/advice の分離と responseSchema 強制の実装箇所を示せ | プロンプト文だけの依頼は違反 |
| R7-2 | 未確定情報への返答方針（「まだ決めていない」等）の定義を引用せよ | 捏造を防ぐ明示的許可がある |
| R7-3 | 相手役の言語統制（N4・1〜2文・訂正禁止）を引用せよ | 3点すべてある |
| R7-4 | API障害時のフォールバック実装と学習者向け文言を引用せよ | 教材が止まらない・不安を与えない |

## R8. キャラクター倫理（アンチパターン集）

| # | 質問 | 合格条件 |
|---|---|---|
| R8-1 | 「日本語が拙い＝能力が低い」と読める描写はないか。あれば引用せよ | あったら違反（最重要） |
| R8-2 | 威圧的な上司・恥をかかせる構図・ステレオタイプはないか。あれば引用せよ | あったら違反 |

## 報告フォーマット

```
セクション: R◯
違反: [番号] 引用「...」 — 理由（1文）
警告: [番号] 引用「...」 — 理由（1文）
確認済み: 番号列挙（証拠は求められたら提示できること）
```

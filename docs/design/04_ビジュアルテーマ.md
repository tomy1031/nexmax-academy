# ビジュアルテーマ「あおぞらパスウェイ」

**作成日**: 2026-07-22
**位置づけ**: `DESIGN.md`（コーポレート由来のトークン定義）を学習アプリ向けに翻案した、実装で使う正式テーマ。矛盾する場合は本書が優先する。

## 1. コンセプト

> カンボジアから日本へ——空の下の、一本の学びの道。

- プログラム名 *Japanese IT Pathway* の「道（みち）」をそのまま世界観にする。TOPページは曲がりくねった道（パスウェイ）に学習モジュールの停留所が並ぶ**まなびマップ**。ゴールは日本のIT企業で働くこと（東京🗼）。
- **文言のトーン規律（重要）**: UIの見た目は明るく楽しくてよいが、**コンセプトは「冒険・探検・クエスト・宝さがし」ではない**。学習者が着実に力をつけて日本で働くための、地に足のついた「学びの道のり」である。「ぼうけん」「たんけん」「クエスト」等の遊びに寄せた比喩を文章に使わない。使ってよいのは「みち」「すすむ」「まなぶ」「ステップ」「マップ」など、道のり・学習として自然な語。楽しさは色・キャラ・アニメ・演出で出し、言葉では誇張しない。
- **空＝コーポレートカラー**。背景世界を NEXT MAKE のスカイブルー系グラデにすることで、会社らしさを「貼る」のではなく「世界にする」。
- 旧アプリ「まなびの島」の優しさは継承するが、カートリッジ棚UI・茶系インク・フクロウのマスコットは採用しない。案内役は世界の住人（ネクマックス）が務める。

## 2. DESIGN.md との関係

| DESIGN.md の規律 | 本テーマでの扱い |
|---|---|
| 二色のブルー（紺=構造 / 空=進捗・リンク） | **維持**。紺 #004f8d はロゴ・見出しアクセント・メインCTA。空 #0288d1 は進捗・リンク・世界の基調 |
| 角丸 12–16px | **増幅**。ボタン16px・カード24px・チップはピル。学習者が長時間座る画面のための柔らかさ |
| M PLUS Rounded 1c は公認の代替 | **主フォントに昇格**（DESIGN.md 自身が「大きい角丸と特に好相性」と明記）。予備に Noto Sans JP |
| 意味色は固定4色 | **色相維持・トーン翻案**: success=葉 #58c273 / warning=陽 #ffc93c / danger=珊瑚 #ff8a70 / info=空 |
| 第3のアクセント禁止 | **意図的に緩和**。学習モジュール/キャラの識別に多色（葉・陽・珊瑚・ぶどう）を使う。マーケ画面ではなく10代後半向け学習ゲームであり、識別色は機能。ただし**UIの構造色は二色のブルーのみ** |
| ライトのみ・ダークは差し替え | 維持 |

## 3. トークン（globals.css が実装）

- 背景世界: `#d8f0fc`（上空）→ `#f4fbff` → `#fff7e8`（地平のクリーム）の縦グラデ
- インク: `#1f3a56`（濃紺スレート。純黒・茶系は使わない）/ soft `#5a7089` / faint `#9db0c2`
- ブランド: navy `#004f8d`（hover `#003c6b`）/ sky `#0288d1`（soft `#e1f2fb`）
- アクセント: leaf `#58c273`/`#3aa458`・sun `#ffc93c`/`#f0a819`・coral `#ff8a70`/`#f2654a`・grape `#a78bfa`/`#8d6ae8`
- 罫線: `#dcebf5`（空色がかった髪の毛線）
- ボタンは「ゲームボタン」: 下に同系深色のハードシャドウ、押すと沈む（squash）

## 4. コーポレートらしさが現れる場所（チェックリスト）

1. 背景の空グラデ（sky系）
2. ロゴ・アプリ名・見出しのアクセント下線（navy）
3. メインCTA（navy、下影 navy-deep）
4. リンク・進捗・フォーカスリング（sky）
5. **ネクマックスの存在**（体＝sky系、胸ロゴ＝navy。§6.1）

## 5. モーション原則

- 出現は spring / pop（`--ease-bounce`）。ホバーで +2〜4% 拡大、タップで 0.95 に沈む
- 環境は常にわずかに生きている: 雲がゆっくり流れ、太陽が回り、キャラが上下に揺れる（bob 3s）
- `prefers-reduced-motion` で全停止（globals.css で一括）
- 演出は学習行為の報酬に紐づける（01ガイド P2）。無意味な常時アニメで注意を奪わない

## 6. キャラクター —「ネクマックス」ファミリー

### 6.1 ネクマックスとは

アプリのナビゲーターは **ネクマックス**——NEXT MAKE の公式ロボットキャラクター（水色のボディ、白いフェイススクリーン、胸に紺のダブルピークMロゴ）。正典画像は `public/img/characters/nexmax/reference.png`（ユーザー提供の原画）。

体色＝コーポレートのスカイブルー系、胸ロゴ＝コーポレートネイビー。**キャラクター自身がコーポレートカラーを着ている**ため、ネクマックスが画面にいるだけで会社らしさが担保される（§4のチェックリストに追加: 6. ネクマックスの存在）。

### 6.2 スマーフ・パターン（正式採用）

1体のマスコットを使い回すのではなく、**役割ちがいのネクマックスを多数登場させる**（スマーフのように）。

| id | 役割 | 登場場面の例 |
|---|---|---|
| guide | ガイドの ネクマックス（みちあんない） | TOP ヒーロー、チュートリアル進行 |
| hello | あいさつの ネクマックス | ログイン、あいさつ・自己紹介系モジュール |
| build | ものづくりの ネクマックス | 開発・実装系モジュール |
| listen | きく ネクマックス | リスニング・ヒアリング系モジュール |
| cheer | おうえんの ネクマックス | クリア演出・励ましフィードバック |
| book | ものしりの ネクマックス | 辞書・ことばアーケード |

- 新しいモジュールを作るときは、担当ネクマックスを1体決める（既存流用 or 新バリアント追加）。**モジュールの顔＝そのネクマックス**として一貫させる。
- 拡張カリキュラム（02設計書）のQA・インフラなどの新領域も、まず「◯◯のネクマックス」で立てる。人間キャラを新造するより世界が薄まらない。
- 人間キャラ（ヘンディ先輩・藤木さん・ニャムさん・大空社長など）は**教材シナリオ内の登場人物**として存続する。ネクマックスは「アプリのUIを案内する住人」、人間キャストは「物語の中の同僚・顧客」——層が違うので共存できる。

### 6.3 実装

- registry とコンポーネント: `src/components/nexmax.tsx`（バリアント表と1対1）
- **キャラクターの手描きSVGは禁止**。画像は Codex の image-gen-2 で生成する（正典参照・マスター記述逐語使用・差分1つ・受入チェック——手順は `docs/skills/codex_image_generation.md`）
- 未生成バリアントは reference.png へフォールバックするため、画像が揃う前でも画面は壊れない

## 7. 画像アセット

キャラクター・シーンイラストは Codex の画像生成スキル（`docs/skills/codex_image_generation.md`）で作成し `public/img/` に配置する。環境装飾（雲・太陽・紙ひこうき）のみ軽量なインラインSVGを許可する。

# 松井社長に 関西風の アクセントを 入れられるか（2026-08-31）

願い #268 の 2件目。**結論: 入れられる。ただし「イントネーションだけ」に 線を 引く。**
2026-08-31 の 指定で「イントネーションだけ」を えらんだ ので、その 形で 入れて ある。

---

## 1. できる のか — 3つの 道

| 道                            | 何を さわるか                                     | 効き目               | この アプリで 使えるか            |
| ----------------------------- | ------------------------------------------------- | -------------------- | --------------------------------- |
| ① 声の 名前を 変える          | `voice`（Schedar・Sadaltager など）               | **方言は 変わらない** | 使える。ただし ねらいには 効かない |
| ② ことばで 話し方を 指示する  | Live の systemInstruction（＝教材の `persona`）    | **中〜大**           | **これを 採った**                 |
| ③ 台本の ことばを 方言で 書く | `opening` / `openers` / `reward` などの 教材の 文 | 大                   | 採らない（下の 2章）              |

- Gemini の 作りおきの 声（30種）は **どれも 標準語の 話者**で、地域の なまりを 選ぶ 欄は 無い。
  声を 変えても「低い／明るい」は 変わるが、関西の 抑揚には ならない。
- 一方 Gemini の 音声生成は、**自然文で style / accent / pace / tone を 指示できる**と
  ドキュメントに 明記が ある（"you can use natural language to structure interactions and
  guide the style, accent, pace, and tone of the audio"）。Live の native-audio モデルは
  TTS と 同じ 声を 使う ので、同じ 指示が 効く。
  出典: <https://ai.google.dev/gemini-api/docs/speech-generation> ／ <https://ai.google.dev/gemini-api/docs/live-guide>（2026-08-31 確認）
- このアプリの Live は `LIVE_TALK_MODELS`（`gemini-3.1-flash-live-preview` ほか）で、
  いずれも native-audio。**指示は 相手に そのまま 届く**。

## 2. なぜ ことばまで 方言に しない のか

学習者は **カンボジアの IT専攻の 学生（N5〜N4）**で、日本語の 学習歴は 1年。
教材の 日本語は 分かち書き・短文・ですます形で そろえて ある（設計01）。ここに
方言の 語（「〜やねん」「〜へん」「ほんま」）を 入れると:

- **教科書に 無い 形**なので、聞いても 辞書でも 引けない。ことばチップも 当たらない。
- 画面の 字（`opening` / `openers` は 教材データ）と 声を そろえる 決まりが ある。
  方言を 声だけに すると **字と 声が ちがう** ことに なり、どちらを 聞けば よいか 分からなくなる。
- ふりがなは 読み辞書で 覆う しくみなので、方言語を 足すと 辞書も その ぶん 育てる ことに なる。

**「大阪の 会社の 社長」という 人柄は、抑揚だけで 十分 出る。** ことばは 標準の まま でも
「この 人は 東京の 人では ない」は 伝わる。学習者の 読む 負担は 1つも 増えない。

## 3. 入れた もの（この 変更で 実際に した こと）

### 3.1 教材の 人格（`content/meetings/kaisha_matsui.json` の `persona`）

```
本社は 大阪です。声の 上がり下がりだけ、やわらかい 関西の イントネーションで 話します。
ことばは 標準の ですます形の ままです。「〜やねん」「〜やで」「〜へん」の ような
方言の 言い方や 方言の ことばは つかいません（学生は 日本語を 習い はじめた ばかりです）。
```

**禁止の れいまで 書く**のが 効き目の 分かれ目だった。「関西風に」だけだと、相手は
語尾まで 方言に する。**やる ことと やらない ことを 両方 書く。**

### 3.2 読み上げの 指示（`src/lib/talkgame/instructions.ts`）

対話ゲームは「運転手は 1人」の 決まりで、画面が `よみあげて: <文>` を 声へ 渡す。
そこに **「その まま 言って ください」**とだけ 書いて あった ので、相手は
**抑揚まで 平らに して 読む**ことが あった。1行 足して 切り分けた:

```
ことばは 変えないで ください。声の 出し方（イントネーション）は、
上に 書いた あなたの くせの ままで かまいません。
```

字と 声を そろえる 決まりは **ことばの 話**で、抑揚の 話では ない——ここを
はっきり 書き分けた。

## 4. 確かめ方（鍵が 要る）

抑揚は **音を 聞かないと 分からない**。機械の 検査では 出ない。

1. 学習者の 画面 `/kaisha/meeting-kaisha_matsui` を 開く（AIの 鍵を 入れた 端末で）
2. 「はじめる ▶」→ 社長の 第一声で「🎤 スタート（マイクを つなぐ）」を 押す
3. 第一声「こんにちは。社長の 松井です。…」を 聞く

聞く ところ: **語尾が 標準の「です・ます」の まま**で、抑揚だけ 上方風に なって いるか。
「〜やねん」などが 出たら、3.1 の 禁止の れいを 増やす。

## 5. 残って いる 手（今回は 採らなかった）

- **強さの つまみを 教材に 置く**（`persona` に 書くのでは なく、`accentStyle: "kansai" | "none"` の ような 欄）。
  他の キャラにも 出身地を 与えたく なった ときに 効く。今は 1人だけ なので、
  スキーマを 増やさず 人格の 文で 済ませて いる。
- **作り置き音声（Live TTS）側にも 同じ 指示を 渡す**。今回 さわったのは 対話（Live 対話）だけ。
  リスニング教材の ナレーションは `NARRATOR_INSTRUCTION` が 別に 持って いる。

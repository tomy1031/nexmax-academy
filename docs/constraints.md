# 制約台帳（constraints）

ユーザーが口頭で伝えた**製品・運用上の制約と好み**の永続台帳。
どのスレッド・セッションも**作業前にこのファイルを読む**（AGENTS.md 多スレッド運用ルール参照）。

**追記のルール**: ユーザーが会話で制約・好みを口にしたら、その場でここに1行追加して
コミットに含める（「前に言ったのに別スレッドに伝わっていない」を無くすため）。
日付と一言の背景を添える。既存項目と矛盾したら、古い方を打ち消し線で残して更新する。

## 製品の制約

| 制約 | 背景・出典 |
| ------------------------------------------------------------------------------ | ---------------------------------------------------- |
| 学習者向けの語彙・文言は N4 前後。「読めるか」が最優先 | 対象はカンボジアIT専攻学生。詳細は docs/design/01 |
| インフラ・API は**無料枠内**で運用する。有料化はユーザーの事前承認が必要 | 繰り返し明言（2026-07 会話） |
| 経由国の表記は「北回り／南回り」に寄せ、特定の国名を出さない | 2026-07 会話での指定 |
| 完成している既存UIの**作り直しをしない**。改良のみ（全画面のゲーム感・臨場感を保つ） | 2026-07-29 単語ゲームUI事故の再発防止 |
| 学習者向け文言の禁止語（「不正解」「間違いです」「ダメ」） | AGENTS.md 絶対規律1（機械検査あり） |

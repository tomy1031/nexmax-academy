## 2. 置き場と 名前（決まって いる）

```
public/img/characters/<id>/mouth/closed.webp
public/img/characters/<id>/mouth/a.webp
public/img/characters/<id>/mouth/i.webp
public/img/characters/<id>/mouth/u.webp
public/img/characters/<id>/mouth/e.webp
public/img/characters/<id>/mouth/o.webp
public/img/characters/<id>/portrait.webp
```

- `VisemeFace`（`src/components/meeting/viseme-face.tsx`）が この 名前で 読む。
  人物カードの `mouth` 欄で 別の URL を 指すことも できるが、**置き場の 決まりに 従うのが 既定**
- 大きさは **正方形 1024×1024**（ヘンディだけ 1254 だが、そろえるなら 1024 でよい）
- `portrait.webp` は **320×384**（しょうかいカード用。正面の 1体を 切り出した もの）

---

## 3. いちばん 大事な こと（ここを まちがえると 画面が ちらつく）

> **背景と 顔は 6枚で まったく 同じに する。口の ところだけが 変わる。**

`VisemeFace` は 音に 合わせて 6枚を **1秒に 何回も** 切りかえます。
髪が 1本 動いた・影が 少し ずれた だけで、**切りかえの たびに 画面が ちらつきます**。

だから 6枚を **別々に 生成しない**でください。作りかたは 2通りの どちらか:

1. **口だけ 重ねる（おすすめ・スタジオと 同じ やりかた）**
   顔の 絵を 1枚 作り、その上に 口の 形 6つを 重ねて 6枚に 書き出す
2. **同じ 参照で 差分 1つだけ**
   `docs/skills/codex_image_generation.md` §2-3 の「差分は 1回に 1つだけ」を 守り、
   **口の 形の 指定だけ**を 変えて 6回 生成する。**ポーズ・服・背景の ことばは 1字も 変えない**

---

## 4. 口の 形（6つ）

`viseme-face.tsx` は かなを 母音に 落として 送ります。形の 指定は こうです。

| ファイル | 形 | 英語での 指定 |
| --- | --- | --- |
| `closed.webp` | 口を 閉じて いる（無音の とき。**いちばん 長く 出る**） | mouth closed, relaxed, slight natural smile |
| `a.webp` | あ | mouth open wide, jaw dropped, rounded oval |
| `i.webp` | い | mouth stretched wide and narrow, teeth slightly visible |
| `u.webp` | う | lips pursed forward into a small circle |
| `e.webp` | え | mouth half open, corners pulled slightly out |
| `o.webp` | お | lips rounded into a medium circle, jaw slightly dropped |

**`closed` が 既定**です。話して いない あいだは ずっと これが 出るので、
いちばん 自然な 顔に して ください。

---

## 5. だれを どう 描くか

**登場人物は 実在の ネクストメイクの 社員・役員が モデル**です（名前を 少し 変えて ある）。
見た目は **人物カードの `looks` を 逐語で 使って ください**（要約・言い換えを しない）。

```
content/characters/okuda.json   の looks
content/characters/fujiki.json  の looks
content/characters/tomita.json  の looks
```

参照画像（`reference.png`）が あるのは ヘンディだけです。
無い 3人は **`sheet.webp`（キャラクターシート）が あれば それを 参照入力に 渡して ください**
（`public/img/characters/<id>/sheet.webp`）。無ければ `portrait.webp` を 渡します。
富田さんは どちらも 無いので、**先に 顔を 1枚 決める**ところから です。

### 富田さんだけ 追加の 手順

1. `content/characters/tomita.json` の `looks` を 読む
2. キャラクターシート（`sheet.webp`）を 1枚 作る（§6.5 の 手順）
3. そこから `portrait.webp`（320×384・正面 1体）を 切り出す
4. その顔で 口パク 6枚を 作る

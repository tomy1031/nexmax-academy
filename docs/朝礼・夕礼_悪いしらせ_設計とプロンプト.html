台帳 #366 ／ 2026-09-11

悪い しらせほど 早く 言う

朝礼・夕礼ステージの やさしいレベルに、この 要素を どう 入れたか。 設計の 考えかたと、機械が それを どう 見張るか、 そして 教材と 検収の プロンプトを どう 書いたかの 記録です。

教材 /asakai ブランチ claude/gifted-ritchie-owcjxd PR #376

01入っていなかった

まず 確かめた ところ、やさしいレベルの 練習には 入って いませんでした。 ページ（読みもの）には 考えかたが 書いて ありましたが、 学習者が それを 口に 出す 場面が 1つも 無く、 おわびの ことばは 教材の どこにも ありませんでした。

どこ 入っていたか 中身
ページ（asakai_lecture） 考えかたは あった 「順調です」だけの 朝礼 → 1週間後に 間に合わないと 分かる、という 対比。 「早く 言う 人は、信頼される 人に なります。」
朝礼メモ（asakai_memo） 無し きのう・きょう・こまりごと・数字の 4つだけ
朝礼の 練習（asakai_kantan） 無し 5日の こまりごとは どれも「分からない」「動かない」で、納期に ひびく 話が 1日も 無い
おわびの ことば 画面には 無し 「すみません」は persona（AIへの 言い渡し）の 中だけ。 学習者には 見えず、しかも この 教材は AIを 呼ばないので 使われても いない
なぜ 落ちたか

設計の 段階で、旧アプリの「バグを 三日 隠した」話を 消して いました。 まんがごと 外した 判断は 正しかった（登場人物を できない人として 描いて いた）のですが、 その 話が 担って いた 学習上の 役割の 引き継ぎ先を 決めて いませんでした。 AGENTS.md の 規律10 が まさに これを 禁じて います—— 「仕組みを 外す ときは、その 仕組みが 担って いた 役割を 先に 書き出し、引き継ぎ先を 決めてから 外す」。

02どこに置くか

教える・やる・ふりかえる の 3点セットで 置きました。 どれか 1つでも 欠けると、前と 同じ ように 静かに 消えます。

役 どこ 何を 置いたか
教える ページに 節を 1つ 追加 「悪い ニュースほど 早く 言う」＋ おわびの 型文 ＋ おわびの 意味を 取りちがえさせない 1枚
見せる 木曜の 見本（司会 ヘンディ） 先輩が 自分の 悪い しらせを 型どおりに 出す。学習者の 直前に 1回
やる 木曜の こまりごとカード おわび＋悪い しらせを 言わないと 箱が 開かない
ふりかえる 金曜の 藤木取締役の 総括 早く 言ったから 間に合った、という 結果を 名指しで 返す

カードを 1枚も 増やさなかった

いちばん 迷った ところです。「悪い しらせ」を 5枚目の カードに するのが いちばん 楽ですが、規律10 の 「1ステージに 枠組みは 1つ」に 反します。 学習者が 覚える 型が きのう・きょう・こまりごと・数字の 4つから 5つに 増え、 ページの 本文とも ずれます。

そこで こまりごとカードの 中の 箱に しました。 悪い しらせは 新しい 話題では なく、こまりごとの 言い方が 変わる だけだからです。 むずかしいレベルが すでに 3つの 箱（こまって いる こと／いつまでに／お願い）を 持って いるので、形も そろいます。

ふつうの 日（月・火・水・金）

こまりごと ＝ 1つの 箱。「◯◯が ◯◯で、こまって います」で 開く。

木曜だけ

こまりごと ＝ 3つの 箱。
こまって いる こと ／ 悪い しらせ ／ お願い

03おわびの設計

おわびだけでは 通さない。悪い しらせだけでも 通さない

ご指定の「伝える際に、謝罪の言葉も一緒に入れる」を 片方だけでは 絶対に 立たない形で 作りました。 判定は allOf（すべての かたまりから 1つ以上 当たる）で、 2つの かたまりを 置いて います。 

{
  "id": "warui1",
  "box": "悪い しらせ",
  "allOf": [
    ["すみません", "申し訳", "もうしわけ"],
    ["間に合わ", "まにあわ", "間に合いません", "おくれ", "遅れ", "むずかし"]
  ]
}

あやまる ことばだけ 言っても 何も 起きません。 悪い しらせだけ 言っても 開きません。 2つ そろって はじめて 1つの 報告に なる、という 設計です。

おわびを 自分を 責める ことばに しない

ここは 慎重に 書きました。N5〜N4 の 学習者に 「まちがえたら あやまる」と 覚えさせると、 悪い しらせを 出す ほど 自分が 悪いという 逆の 学習に なります。 それでは 隠す 方向に 進みます。ページに この 1枚を 入れました。

ページの 本文（そのまま）

おわびは、自分が わるいと 言う ための ことばでは ありません。 相手の 予定が 変わるから 言う ことばです。 早く 言えば、みんなで 直せます。おそく 言うと、直せません。

司会の 受け止めも 合わせました。木曜に 言えた ときは 「早く 言って くれて 助かります。金曜日の 前に 分かりました。」と 事実を 返します。言えなかった ときも 責めず、言い方を 見せてから 自分で 段取りします。

やさしいと むずかしいで 何を 変えたか

やさしい（朝礼） むずかしい（夕礼）
悪い しらせ カードの 行に 書いて 渡す（「このままだと 金曜日までに 間に合わない」） メモ10行から 自分で 見つける（明日 18人に 見せるのに 答えが 決まって いない）
箱の 名前 こまって いる こと ／ 悪い しらせ ／ お願い おわびと 悪い しらせ ／ いつまでに ／ お願い
型文 穴埋めで 渡す（「すみません。◯◯が 金曜日までに 間に合わないかも しれません。」） 問いかけだけ（「あしたに ひびく ことなら、さいしょに「すみません」」）

045日の物語

こまりごとの 大きさが 週の 中で 育ち、木曜で いちばん 重く なり、 金曜で 回収される、という 並びです。木曜に 置いたのは 週の ゴール（金曜日までに テストを ぜんぶ 通す）に ぎりぎり 間に合う 最後の 日だからです。 水曜では まだ 余裕が あり、金曜では もう 遅い。

曜日 こまりごと おわび ねらい
月 一覧の 書き方を 知らない — 小さい こまりごとを 出す 練習。見本も こまりごとを 1つ 出す
火 ありません — 「無い」も 報告だと 知る
水 部品を 自分で 作るか 分からない — 判断を 人に 聞く
木 メールが 来ない。このままだと 金曜日に 間に合わない 要る 納期に ひびく ことを、その日の 朝に 言う
金 ありません（直った） — 藤木取締役が「早く 言ったから 間に合った」と 返す
金曜の 総括（そのまま）

木曜日は「金曜日までに 間に合わないかも しれません」と、朝に 言って くれました。 だから その 日の うちに ニャムさんが 入って、きょう 間に合いました。 もし 金曜日の 朝に 聞いて いたら、直す 時間は ありませんでした。 悪い しらせを 早く 出す 人は、チームに いちばん 助かる 人です。

05判定の作り

AIを 呼ばない

この 教材の 判定は ことばの 照合だけで 動きます。AIに 「この カードを 開いて よいか」を 聞くと、同じ 答えでも 日に よって 開いたり 開かなかったり し、 難しさが 相手の さじ加減で 変わります。 鍵が 無い 教室でも 本番でも 同じ 合否に なり、CI でも 5日 通しで 確かめられます。

3つの 見かた

見かた いつ 使うか この 教材での れい
keywords どれか 1つ 当たれば よい こまって いる こと（メール／来ない／3回…）
minHits いくつ 当たれば よいかを 決める むずかしいの こまりごと（2語 以上）
allOf すべての かたまりから 1つ以上 おわび＋悪い しらせ／お願い（だれに＋何を）
なぜ allOf が 要るか

数だけで 見ると、開いては いけない ものが 開きます。実例: お願いの 箱は「見て」「ほしい」で 2つ 当たるので、 「だれかに 見て ほしいです」でも 立って いました（だれに が 無い）。 同じ 罠を 金曜でも 踏みました——メモに「ヘンディさんが」と「…して ほしい」が 別々に あったので、棒読みで お願いの 箱が 開いて いました。 頼む 形の ことばだけに 絞って 塞ぎました。

かなだけで 打つ 人を 落とさない

N5 の 学習者は かなで 打ちます。 「すみません。きんようびまでに まにあわないかも しれません。」が 開かないのでは 意味が ありません。 やさしいレベルの 漢字の 当たりことば 40語 ぜんぶに かなの 形を そえました （間に合わ → まにあわ など）。開く 側にしか 効かないので、 増やしても 難しく なりません。

あわせて、1字の 当たりことばは 永久に 当たらないことも 見つけました （照合は 2字 以上でしか 当てません。誤爆が 多すぎる ため）。 紙・表・欄・形・文・昼 の 6語が 死んで いたので 直し、 二度と 書けない ように 機械の 検査を 足しました。

さいごの 1行が 大事な ところです。見本は ヘンディさんの 仕事の 話なので、 写しても おわびの 型しか 移りません。 写すだけでは 満点に ならない——中身は 自分の カードから 取る 必要が あります。

07プロンプトの作り

教材の 中の プロンプト（2本に 分けて 書く）

教材は persona（相手役の 人格）と judgePrompt（見かた）を 別々に 持ちます。同じ 1本に すると、 話し方を 直すたびに 採点の 基準が 黙って 動くからです。

persona — どう 話すか

だれで、どこまで 話し、何を 言わないか。 「返しは くりかえし＋ひとこと、2文まで」 「ほめる ことばを 足しません。事実を くりかえします」 「つぎに 何を 聞くかは 画面が 決めます」

judgePrompt — 何を 見るか

何が 言えたら 言えたことに するか。 段（natural / rough / hard）と、 直すのは 1つだけ、という 決まり。

プロンプトに 書いても 守れない ことが ある

この 教材で いちばん はっきり 出た 学びです。 「がんばったね、などの 無駄な 表現を 省く」という ご指定は プロンプトの 文言だけ 直して あり、道具の スキーマでは ほめことばが 必須の ままでした。 つまり 鍵の ある 教室では、AI は 名指しできる ことが 無い 回でも 何かを 書く しか なく、中身の 無い ほめことばが 出つづけて いました。 必須から 外し、画面は 空なら 欄ごと 出さない ように しました。 プロンプトの お願いは、型で 支えないと 守られません。

検収エージェントの プロンプト

この ターンは 5体を 同時に 走らせました。 プロンプトは どれも 同じ 6つの 部品で 書いて います。

  1. 担当を 1つに 絞る（「やさしい側だけ 見る。むずかしい側は 別の エージェント」）
  2. 読む ファイルを 名ざす（探させない。探すと 時間が そこで 溶ける）
  3. 実装の 事実を 先に 渡す（「判定は ことばの 照合だけ。AI は 呼んで いない」）
  4. 見る ところを 番号つきで（7〜20項目。あいまいな「よく 見て」を 書かない）
  5. 証拠の 形を 指定する（「入力した 文 → 開いた カード の 表で 出す」「引用できない 指摘は 出さない」）
  6. 直させない（「読むだけ。直しは 主スレッドが やる」）

いちばん 効いたのは 3と5です。 前提を 渡さないと「AI の 判定が 不安定では ないか」という 当たらない 指摘に 時間を 使い、 証拠の 形を 決めないと 印象論が 返って きます。 実際、やさしい側の エージェントは 指示どおり 自分で 発話文を 組み立てて 純関数を 叩き、 「型文だけに 頼ると 月・金は 3/4 に なる」という 数字を 持って 帰って きました。

エージェント 担当 いちばん 効いた 発見
やさしい側の 試遊 N5溺れかけ／N4標準 途中で 閉じると 月曜に 戻る（しおりが 無い）
むずかしい側の 試遊 N3挑戦／N4背伸び 金曜の お願いの 箱が 頼まなくても 開く／司会の 聞き返しが 画面の 外
ルーブリック 順路・移植・枠組み こまりごとの 見本が 30本 ぜんぶ「ありません」
コード検収 状態機械・合否・大きさ れいを 写すと 板は ❌ なのに 合否は ⭕
UI 最終チェック 画面の 字・390px けっかの 上に「ステージ クリア」が かぶさる

08機械に落とす

この ターンの いちばん 大きな 学びは、 検査が 見て いない ことは、検査では 気づけないという ことでした。 ふりがなの 覆い検査の 入り口は 教材の 種類ごとに 手で 書いた 一覧で、 朝礼・夕礼の 5場面を 1つも 歩いて いませんでした。 足したとたん 142件の 裸の 漢字と 読みちがいが 出ました—— 「先生 18人（ひと）に 見せる」「行（い）は 1つに まとめます」「通知が 来（き）ない」。

そこで、同じ 形の 事故が 二度と 起きない ように、 穴の 種類ごとに 見張りを 足しました。

起きた こと 種類 足した 見張り
検査が asakai を 歩いて いない 欄を 足した 人が 検査を 足し忘れる 教材の JSON を まるごと 歩いて、検査の 外に 出て いる 欄を 見つける。いまの 借金（22種）を 記録し、増えたら 落とす
板は「4 / 4」なのに 司会は 聞き返す 同じ ことを 2か所で 数えて いた 総当たりで 状態を 作り、聞き返す 先が 無い ＝ どの カードも ⭕ を 見る
れいを 写すと 板は ❌ なのに 合否は ⭕ 言えなかった ことが 言えた ことに 化ける 打ち切った カードは 動かない ことを 直に 見る
けっかの 上に「クリア」が かぶさる 書く 順番 5日 通しプレイして、合否の 字と 数が 読める ことを 見る
途中で 閉じると 月曜に 戻る しおりが 無い 月曜を 終えて リロードし、火曜から つづく ことを 見る
390px で 板と 入力欄が 画面の 外へ 親が スクロールの 器に なる 入力欄が 見える 位置で、板も 見える ことを 座標で 見る
悪い しらせが 練習に 無い 役割の 引き継ぎ先を 決めずに 消した おわびを 求める 箱が ある／片方だけでは 立たない／ 見本か れいで 見せて いる／ページが 先に 教えて いる の 4本
借金は 見えるように する

まるごと 歩く 検査を 足したら、のべ 1617件が 検査の 外に 出て いる ことが 分かりました。いちばん 大きいのは クエスト教材まるごと（583件）——30場面の セリフも 4択の 本文も、 1つも 検査されて いません。朝礼・夕礼と まったく 同じ 形の 穴です。 いま ここで ぜんぶ 直すのは 別の 仕事なので、 一覧に 書いて 記録し、増えない ことだけを 機械に 守らせました。 1つ 直したら 1行 消す 運用です。

09残り

  • 箱ごとの 聞き返し。いまは 2回目が 3つの 箱を まとめて 名ざす 形で 代えて います

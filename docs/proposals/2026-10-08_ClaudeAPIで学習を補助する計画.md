# Claude API で 既存の 教材の 学習を 補助する 計画

**日付**: 2026-10-08 ／ **ブランチ**: `claude/claude-api-learning-enhancement-f4f2fb` ／ **願い**: #586
**位置づけ**: 提案書（プランニング）。**実装はまだしていない。**
完成UIの 作り直しは しない（constraints「完成している既存UIの作り直しをしない」）。いまの 画面に **判定の 出どころを 1つ 足す**だけに する。

## 0. 前提（ユーザーの 指定）

- Claude API は **毎月 100ドルの 無料付与**。生徒は **20人**
- **授業中だけ** 使う。**授業時間に よる 自動の 切り替え**と **手動の ON/OFF** を 置く
- 強化できる 箇所に **補助として** 入れる。とくに 報連相：連絡の ような **文書作成**
- モデルは Haiku 5.5 の 予定。Opus で ないと だめな 箇所が あれば 考える
- 学習者は N5〜N3（実際は N4 未満が 多い。constraints「製品の 制約」2行目）

## 1. 結論（3行）

1. **効くのは「自分で 書く」教材**。いまは **書けば 点**（文字数だけ）か、**生徒が 自分の Gemini の 鍵を 入れた ときだけ** AIが 見る。Claude を 授業中の 共有の 枠に すれば、**鍵の 無い 生徒にも 毎回 ⭕✗と ひとことが 出る**
2. **モデルは Haiku 5.5 で 足りる**（2026-10-07 公開。Haiku 4.5 の 約 1/10 の 値段）。Opus が 要る 箇所は 無い。費用は 多めに 見て **月 5〜10ドル**
3. 声の 会話（ミーティング・たいわ・松井社長）は **Gemini Live の まま**。Claude は 声を 扱えないので、入れるのは **文字の 判定**だけ

## 2. 強化できる 箇所（効く 順）

判定の 欄の「鍵あり」＝ 生徒が 自分の Gemini の 鍵を 入れて いる ときだけ（BYOK。`localStorage["nexmax.geminiKey"]`）。

### 入れない ところ

- **声の 会話そのもの**（ミーティング・たいわ・松井社長の 対話ゲーム）— Claude は 声を 扱えない。いまの Live の 中の 判定で 足りて いる
- **教材づくり**（先生の スタジオ）— constraints「生成は Codex を 第一」の まま
- **生徒が 自由に 質問できる AIチャット** — 費用が 読めず、返事が レベルを 超えやすい

## 3. モデルの 選びかた

| モデル | 料金（100万トークン 入力／出力） | 1回の めやす | 月の めやす（§4） | 判断 |
|---|---|---|---|---|
| **Haiku 5.5**（`claude-haiku-5-5`） | 0.10ドル／0.50ドル | 約 0.07セント | **約 5〜10ドル** | **採用**。いちばん 速い（20人が 待たない） |
| Haiku 4.5（`claude-haiku-4-5`・旧） | 1ドル／5ドル | 約 0.4セント | 約 30ドル | 使わない（5.5 の 方が 安くて 新しい） |
| Sonnet 5.5（`claude-sonnet-5-5`） | 2ドル／10ドル | 約 1.3セント | 約 100ドル | 全部には 使えない。§3 の 比べで 必要と 出た 教材だけ |
| Opus 5.5（`claude-opus-5-5`） | 4ドル／20ドル | 約 3セント | 約 230ドル | **使わない**。枠を 超える。考える 処理を 切れず 遅い |

料金は 2026-10-08 に 公式の 資料で 確かめた 値（入力 10万トークン 以下の とき）。

- 学習者向けの 判定は **型の 決まった 短い 判断**（観点ごとの ⭕✗・ひとこと・直した 文）。Haiku 5.5 で 足りる 見込み
- 返事の 形は **型を 指定して 受ける**（structured outputs）。いまの Live の「関数呼び出しで JSON を もらう」と 同じ 形に そろえる
- **Haiku 5.5 の 注意**（公式の 移行ガイド）
  - 考える 処理が 既定で 入る（effort の 既定は `medium`）。判定は **`low` から 試す**。考えた ぶんも 出力として 数えるので `max_tokens` に ゆとりを 持たせる
  - `temperature` などは 送らない（400 に なる）。最後を アシスタントの 発言で 終える 書きかた（prefill）も 400
  - 安全の 仕組みが 断る ことが ある（`stop_reason: "refusal"`）。そのときは アプリの 判定へ 落とす
  - 同じ 文でも Haiku 4.5 より 約 30% 多く 数える（見積もりは この 分を 入れて ある）
- **不安が 残るのは「ブラッシュアップの 文の 自然さ（敬語）」だけ**
  - 本物の 生徒の 答え 30本で Haiku 5.5（`low`・`medium`）と Sonnet 5.5 を 並べて 比べ、差が 出た 教材だけ Sonnet に する
  - Haiku 5.5 は 安いので、**`medium` に 上げても 月 10ドル 前後**。まず effort で 質を 上げ、それでも 足りない ときだけ Sonnet
  - いまの ものさし合わせ（`npm run eval:taiwa`）と 同じ 流儀
- 漢字の 制限（`src/lib/ai-kanji.ts`）は モデルに 関係なく いまの 検査と 1回の 言い直しが 守る

## 4. 費用の 見積もり（多めに）

- **1回**: 入力 約6,500トークン（指示＋漢字の 一覧＋問い＋お手本＋答え。うち 約5,850 は 毎回 同じ → キャッシュで 1/10）、出力 約1,100トークン（日本語の JSON 約800＋考える ぶん 約300）
- **回数**: 20人 × 1授業 30回 × 月13授業（火・水・金）＝ **月 7,800回**
- **Haiku 5.5**（`low`）: 約 0.07セント × 7,800 ＝ **約 5ドル**（キャッシュが 効かなくても 約 9ドル。`medium` でも 約 12ドル まで）
- 100ドルの 枠に **10倍 以上の ゆとり**。§2 の 8か所 ぜんぶに 広げても 収まる 見込み
- 枠が 余る ぶんは、**授業中だけ という 決まりは そのまま**に して、質（effort を 上げる・一部を Sonnet 5.5）に 回せる

## 5. ON/OFF の しくみ

先生の 画面（`/admin` の サイドバーに「AIチェック」を 1つ 足す）:

| 設定 | 中身 |
|---|---|
| モード | **自動**（授業の 時間だけ ON）／**ON**／**OFF** の 3つ |
| 授業の 時間 | 曜日と 時刻（**カンボジア時間**）。既定は 火・水・金 17:30〜（終わりの 時刻は ユーザーに 確かめる） |
| 月の 上限 | 例 90ドル。超えたら その月は 自動で OFF |
| 1人の 上限 | 例 1授業 60回（1人が 枠を 使いきらない ため） |
| 今月の 使用量 | 金額・回数・生徒ごとの 回数を 表示 |

- **OFF の ときの 動き**: いまの「鍵なし」と 同じ（お手本だけ／アプリの 判定だけ）。**学習者は 止まらない**
- **順番**: Claude（授業中）→ Gemini（生徒が 鍵を 入れて いれば）→ アプリの 判定。授業外でも 鍵の ある 生徒は いまどおり
- **二重の 止め**: アプリの 月の 上限に 加えて、Anthropic の 管理画面でも 使用上限を 100ドルに する（請求が 来ない 保険。ユーザーの 手作業 → タスクボード）

## 6. AIを 呼ぶ 場所

- **Cloudflare（いまの アプリの サーバ）では 呼ばない**
  - Cloudflare は 香港で 動く ことが あり、**Claude API は 香港から 使えない**（Anthropic の 対応地域一覧で 確認ずみ 2026-10-08）
  - Gemini を ブラウザ直に 移した のも 同じ 理由（`src/lib/ai/live-token.ts:6-19`）
  - constraints「Worker に 仕事を させない」とも 合う
- **Supabase の Edge Function を シンガポール（`ap-southeast-1`）に 固定して 呼ぶ**
  - `supabase.functions.invoke(..., { region: FunctionRegion.ApSoutheast1 })`
  - Cambodia・Singapore は Anthropic の 対応地域
- 鍵（`ANTHROPIC_API_KEY`）は **Supabase の 関数の 秘密**に だけ 置く
  - Cloudflare・`.env`・ブラウザには 置かない（絶対規律4）
  - 念のため `scripts/check_build_env.mjs` の `FORBIDDEN_AT_BUILD` に 足す
- **ログイン済みの 生徒だけ** 呼べる（関数で JWT を 確かめる）。デモモード（Supabase 無し）は 常に OFF → CI・E2E は いまの まま 動く
- 送るのは **問い・お手本・答えの 文だけ**（名前・メールは 送らない）

| `src/lib/ai/claude-check.ts` | 返す 形は いまの `kotae_no_check`（`src/lib/quiz/ai-review.ts`）・`BugReviewResult`（`src/lib/quiz/bugreport.ts:287`）と 同じ → **画面の 部品は 変えない** |
| `/admin` の「AIチェック」 | §5 の 表 |

## 7. 規律との 関係

| 規律 | 扱い |
|---|---|
| 絶対規律1（結果を ぼかさない） | 返事は **判定が 先**（⭕✗）、つぎの 行動を 1つ。いまの 部品の 出しかたを そのまま 使う |
| 絶対規律3（選択式は 読解だけ） | 書く 教材を 強くする 方向なので 合う |
| 「採点は やさしく」（constraints） | **点・合否・関門は アプリが 持つ まま**。Claude は 足し算（取りこぼしを 拾う）と ひとこと だけ |
| 「Gemini は Live だけ」（constraints 運用） | Gemini の 枠の 話。Claude の 文字の 判定は 別勘定なので ぶつからない（2026-09-09 提案 §6 で「連絡メモの AI採点」を 落とした 理由は Gemini の 枠。**Claude なら 前提が 変わる**） |
| 08 §0.1「生徒の 回答を 外部へ 送らない」 | これは 性格診断の 話。学習の 答えは いまも Gemini に 送って いる。§2 #8（先生向けの まとめ）だけは 20人ぶんを まとめて 送るので **ユーザーに 確かめる** |
| 費用（「有料化は 事前承認」） | §5 の 二重の 止めで 100ドルを 超えない |

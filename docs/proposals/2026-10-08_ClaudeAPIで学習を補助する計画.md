## 1. 結論（3行）

1. **効くのは「自分で 書く」教材**。いまは **書けば 点**（文字数だけ）か、**生徒が 自分の Gemini の 鍵を 入れた ときだけ** AIが 見る。Claude を 授業中の 共有の 枠に すれば、**鍵の 無い 生徒にも 毎回 ⭕✗と ひとことが 出る**

## 2.5 学びかたの 提案（Haiku で 作れる 新しい 練習）

ねらい（2026-10-08 の 指定）: **正確で ナチュラルな 日本語**を、**どうして その 日本語が いいのか** まで 分かって 学ぶ。**文法と 文章表現**も 強くする。
§2 の 教材に **足す**（新しい 教材は 作らない）。いまの 画面は「⭕✗＋ひとこと＋ブラッシュアップ回答 1本」（`src/components/quiz/check-parts.tsx:82`）。

| # | 案 | いま | 変えると | 学びの ねらい |
|---|---|---|---|---|
| A | **直しの「どうして」カード** | ブラッシュアップ回答が 1本 出るだけ。どこが・なぜ 変わったかは 自分で 比べる（N4 未満には むずかしい） | 自分の 文と よい 文を 並べ、**変わった 所に 色**。変わった 所ごとに **「どうして」を 1行**（やさしい 日本語＋英語の ひとこと）。**1回 3か所 まで** | 「どうして その 日本語が いいのか」 |
| B | **自分で 直してから 答えを 見る** | ⭕✗の すぐ あとに ブラッシュアップ回答が 見える → 写すだけに なりやすい | 1回目は **「どこを」と「何を」だけ**（例:「2文目の『を』を 見なおそう」）。自分で 書き直して もう一度 チェック。**2回目の あと**に お手本と A の カード | 文法・表現を **自分で 直す 力** |
| C | **読み手の こたえ** | ⭕✗は 観点ごとで、「相手に 伝わったか」は 見えない | 受け取った 人（藤木さん・チーム）として **「分かった こと／分からなかった こと」を 2〜3行**で 返す | 連絡・報告が **伝わる 文**に なる（まんが「連絡した つもり？」を 自分の 文で 体験） |
| D | **わたしの 直しノート**（＋3問 ドリル） | 直しは その場で 消える | よく 直された **言いかたを トップ3**で 見せる（例:「〜を 確認して ください → 〜の 確認を お願いします」）。授業の さいごに **自分の 文から 作った 穴うめ 3問** | 同じ まちがいを くり返さない |

### A〜D の 決まりごと

- **直しは 2種類に 分けて 見せる**
  - 「**直す**」＝ 伝わらない・まちがい
  - 「**もっと 自然**」＝ いまの ままでも 通じる
  - 「意味が 伝われば 合格」「言い方に 柔軟に」（constraints）を 守る
  - 合否は 変えない。合格の 文にも「もっと 自然」は 出してよい
- **色を 付ける 場所は アプリが 決める**
  - 2つの 文を アプリが 比べて 色を 付ける。AIに 位置を 言わせない（ずれない ため）
  - AIが 書くのは「どうして」の 1行 だけ
- **「どうして」に 文法の 種類の 名前（助詞・敬語 など）を 札として 出さない**
  - 1行の 説明に する
  - 種類の 札を 並べると **本文に 無い 枠組み**に なる（規律10）
  - 要る ときは 先に 講義の 本文へ 足す
  - D の トップ3も **種類では なく 実際の 言いかえ**で 見せる（N4 未満には 具体の 方が 分かる）
- **読み手（C）と 直し（A）は 別の 声**
  - 01ガイド P12「AIは『相手役』と『コーチ』に 分離する」
  - 読み手は 文法を 直さない。分からなかった ことを 言うだけ
  - 登場人物が 失敗する 描写は しない（規律10）
- **回数**
  - B は「言い直しは その場で 1回まで（2回目の あとは かならず 進む）」（constraints）と 同じ
  - 費用は 2倍に なっても 月 10〜20ドル
- **正確さ**
  - 本物の 答え 30本で、A の「どうして」が 正しいかを **先生が 確かめてから** 出す（§3 の 比べと 同じ 回）
  - まちがった 説明は 学習者に とって **いちばん 害が 大きい**
- **次の 候補（いまは 入れない）**
  - 同じ 中身を、相手を 変えて 書く（同僚の チャット → 上司 → 社外メール）
  - 敬語の 段の 理由が 分かる
  - ただし 新しい 問いが 要るので 教材の 側で 決める

## 3. モデルの 選びかた

| Haiku 4.5（`claude-haiku-4-5`・旧） | 1ドル／5ドル | 約 0.4セント | 約 30ドル | 使わない（5.5 の 方が 安くて 新しい） |
| Sonnet 5.5（`claude-sonnet-5-5`） | 2ドル／10ドル | 約 1.3セント | 約 100ドル | 全部には 使えない。§3 の 比べで 必要と 出た 教材だけ |
| Opus 5.5（`claude-opus-5-5`） | 4ドル／20ドル | 約 3セント | 約 230ドル | **使わない**。枠を 超える。考える 処理を 切れず 遅い |

料金は 2026-10-08 に 公式の 資料で 確かめた 値（入力 10万トークン 以下の とき）。

- 学習者向けの 判定は **型の 決まった 短い 判断**（観点ごとの ⭕✗・ひとこと・直した 文）。Haiku 5.5 で 足りる 見込み
- 返事の 形は **型を 指定して 受ける**（structured outputs）。いまの Live の「関数呼び出しで JSON を もらう」と 同じ 形に そろえる
- **Haiku 5.5 の 注意**（公式の 移行ガイド）
  - 考える 処理が 既定で 入る（effort の 既定は `medium`）。判定は **`low` から 試す**。考えた ぶんも 出力として 数えるので `max_tokens` に ゆとりを 持たせる
  - `temperature` などは 送らない（400 に なる）。最後を アシスタントの 発言で 終える 書きかた（prefill）も 400
  - 安全の 仕組みが 断る ことが ある（`stop_reason: "refusal"`）。そのときは アプリの 判定へ 落とす
  - 同じ 文でも Haiku 4.5 より 約 30% 多く 数える（見積もりは この 分を 入れて ある）
- **不安が 残るのは「ブラッシュアップの 文の 自然さ（敬語）」だけ**
  - 本物の 生徒の 答え 30本で Haiku 5.5（`low`・`medium`）と Sonnet 5.5 を 並べて 比べ、差が 出た 教材だけ Sonnet に する
  - Haiku 5.5 は 安いので、**`medium` に 上げても 月 10ドル 前後**。まず effort で 質を 上げ、それでも 足りない ときだけ Sonnet
  - いまの ものさし合わせ（`npm run eval:taiwa`）と 同じ 流儀
- 漢字の 制限（`src/lib/ai-kanji.ts`）は モデルに 関係なく いまの 検査と 1回の 言い直しが 守る

## 4. 費用の 見積もり（多めに）

- **1回**: 入力 約6,500トークン（指示＋漢字の 一覧＋問い＋お手本＋答え。うち 約5,850 は 毎回 同じ → キャッシュで 1/10）、出力 約1,100トークン（日本語の JSON 約800＋考える ぶん 約300）
- **回数**: 20人 × 1授業 30回 × 月13授業（火・水・金）＝ **月 7,800回**
- **Haiku 5.5**（`low`）: 約 0.07セント × 7,800 ＝ **約 5ドル**（キャッシュが 効かなくても 約 9ドル。`medium` でも 約 12ドル まで）
- 100ドルの 枠に **10倍 以上の ゆとり**。§2 の 8か所 ぜんぶに 広げても 収まる 見込み
- 枠が 余る ぶんは、**授業中だけ という 決まりは そのまま**に して、質（effort を 上げる・一部を Sonnet 5.5）に 回せる
- §2.5 の B（自分で 直して もう一度）と C（読み手の こたえ）で 回数が 2〜3倍に なっても **月 15〜30ドル**

## 5. 使える 時間の 設定（大学 × 期生）

**授業は 火・水・金 17:30〜19:00**（カンボジア時間。2026-10-08 の 指定）。
大学と 期生は 生徒ごとに すでに 持って いる（`profiles.university` ＝ AUPP／CADT／講師・スタッフ、`profiles.cohort` ＝ 1〜5。`src/lib/school.ts`）ので、**その 組を 単位に する**。

先生の 画面に「**AIの 時間**」を 1つ 足す（サイドバーの「じゅんろの 鍵」`/admin/lock` の となり。作りも 同じ 流儀）:

| 欄 | 中身 |
|---|---|
| 組 | 大学 × 期生（AUPP 1〜5期・CADT 1〜5期・講師・スタッフ）。**1行 1組** |
| 時間わく | 曜日（月〜日を えらぶ）＋ はじめ・おわり（カンボジア時間）。**1組に 何本でも**（補講の 曜日を 足せる） |
| 手動 | **自動**（時間わくの とき だけ）／**いまから ◯時まで ON**（補講・先生の 試し）／**きょうは OFF** |
| ぜんぶ 止める | 全部の 組を 一度に 止める（費用や 不具合の ときの 非常ボタン） |
| 月の 上限 | 例 90ドル。超えたら その月は 全部 OFF |

- **設定の 無い 組は 常に 使えない**（2026-10-08 の 指定）

  - 講師・スタッフも 同じ。先生が 試す ときは「いまから ◯時まで ON」を 使う
- 判定は **AIを 呼ぶ 関数の 側**で する（生徒の 端末の 時計を 信じない）
- 最初の 設定は 空で 始める（どの 組が 火・水・金の クラスかは 先生が 入れる）

## 6. AIを 呼ぶ 場所

- **Cloudflare（いまの アプリの サーバ）では 呼ばない**
  - Cloudflare は 香港で 動く ことが あり、**Claude API は 香港から 使えない**（Anthropic の 対応地域一覧で 確認ずみ 2026-10-08）
  - Gemini を ブラウザ直に 移した のも 同じ 理由（`src/lib/ai/live-token.ts:6-19`）
  - constraints「Worker に 仕事を させない」とも 合う
- **Supabase の Edge Function を シンガポール（`ap-southeast-1`）に 固定して 呼ぶ**
  - `supabase.functions.invoke(..., { region: FunctionRegion.ApSoutheast1 })`
  - Cambodia・Singapore は Anthropic の 対応地域
- 鍵（`ANTHROPIC_API_KEY`）は **Supabase の 関数の 秘密**に だけ 置く
  - Cloudflare・`.env`・ブラウザには 置かない（絶対規律4）
  - 念のため `scripts/check_build_env.mjs` の `FORBIDDEN_AT_BUILD` に 足す
- **ログイン済みの 生徒だけ** 呼べる（関数で JWT を 確かめる）。デモモード（Supabase 無し）は 常に OFF → CI・E2E は いまの まま 動く
- 送るのは **問い・お手本・答えの 文だけ**（名前・メールは 送らない）

## 7. 規律との 関係

| 規律 | 扱い |
|---|---|
| 絶対規律1（結果を ぼかさない） | 返事は **判定が 先**（⭕✗）、つぎの 行動を 1つ。いまの 部品の 出しかたを そのまま 使う |
| 絶対規律3（選択式は 読解だけ） | 書く 教材を 強くする 方向なので 合う |
